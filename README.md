# AI Chatbot Authentication System

A console-based C++ application that integrates a secure user authentication system with an interactive AI chatbot. This project was developed as a final project for the Data Structures and Algorithms course.


## Features

### User Authentication
- User Sign Up
- Secure Login System
- Email Validation
- Password Validation
- Age Verification

### AI Chatbot
- Interactive chatbot conversation
- Handles 100+ predefined questions
- Natural text normalization
- Randomized responses

### Data Structures Used
- 'unordered_map'
- 'vector'
- 'queue'
- 'stack'

### Additional Functionalities
- Conversation History
- Undo Last Interaction
- Menu-Driven Interface
